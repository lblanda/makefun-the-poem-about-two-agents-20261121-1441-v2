The poem about two agents agreeing. Your program writes one text (a short poem about agency: the power to choose and to act), an AI judge compares the texts two at a time, and the 20 best win rates share $35.

## Run it

```sh
python3 main.py
```

Writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Self-contained, stdlib only, no network, deterministic.
